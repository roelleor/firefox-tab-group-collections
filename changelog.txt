Tab Group Collections Changelog

Format: plain text, based on Keep a Changelog.

Unreleased

Changed
- The sidebar review invitation becomes eligible after successful collection actions on five distinct days, without the additional two-week wait. Existing reminder cooldowns are unchanged.

1.8.1 - 2026-11-11

Fixed
- Enter from quick-panel search now focuses New Window immediately when the first saved collection needs opening choices. A second Enter opens it, while Down selects Append Here. Saved collections still open directly in a fresh window.

1.8.0 - 2026-11-04

Changed
- Starting with this release, the extension is licensed under the MIT License with Commons Clause License Condition v1.0. Use remains free, including at work; selling products or services whose value derives entirely or substantially from the extension is restricted by the combined license.
- Included the complete combined license in extension packages and documented the terms in the repository. Permissions for earlier versions already released under MIT are unchanged.
- No extension functionality changes in this release.

1.7.0 - 2026-11-04

Added
- Full sidebar keyboard control: Filter receives initial focus, arrows navigate collections, groups, and expanded choices, and Tab reaches every management action. Collection headings keep their expand/collapse behavior.
- Keyboard group reordering with Alt+Up/Down and access to the existing move panel from the drag handle. An expandable Keyboard controls guide is included in the sidebar.

Changed
- Enter from search activates the first collection in either panel, using its existing Open or Go to action.
- Sidebar opening choices now use New Window and Append Here, matching the quick panel. Escape closes sidebar choices, clears filtering, then returns to Filter while keeping the sidebar open.

Fixed
- Sidebar focus and unfinished move destinations survive live updates, group renames, and transitions between open and saved groups. Relocated focused controls stay visible, while passive refreshes preserve manual scrolling.
- Reduced sidebar refresh work for large group lists by skipping closed move forms and resolving focus targets once per update.
- Firefox Home is now recognized as an empty window when opening saved collections, alongside blank and New Tab pages. Restoring a collection replaces the unchanged placeholder tab.
- Closing collections, deleting groups, and deleting collections with their groups no longer create additional saved copies in Firefox. Empty windows retain a blank tab.
- Canceled close and delete actions preserve surviving groups. Interrupted collection closes restore partly closed groups through Firefox's undo history, with saved URL recovery when undo is unavailable.

1.6.0 - 2026-10-22

Added
- Configurable Firefox keyboard shortcuts to open the quick panel and toggle the side panel. Assign keys in Add-ons → Manage Extension Shortcuts; neither command has a default shortcut.

1.5.0 - 2026-10-22

Added
- Quick popup search for collection and tab group names, with automatic focus, highlighted matches, and matching group previews. Individual tab titles and URLs are not searched.
- Up and Down navigate popup results and expanded New Window and Append Here choices. Right opens saved collection choices, Left closes them, and Enter toggles them on the collection row. Down enters results from search. Escape clears the search or closes the popup.
- Quiet review links in the quick popup and sidebar, plus a dismissible sidebar invitation after sustained use. Showing or dismissing the invitation pauses it for three months; opening any review link pauses it for a year.

Changed
- Compact popup header places the Side panel button beside the title, leaving room for search without increasing the header height.
- Saved collections open directly in the current window when it contains only an empty new tab.

Fixed
- Quick popup width remains fixed while typing, filtering, and expanding collection opening choices; long no-match messages wrap within the panel.
- Groups created by splitting or duplicating native Firefox groups retain separate identities and names during synchronization and reopening.
- Repairing duplicate group identities preserves closed group snapshots and saved tab URLs rather than guessing ambiguous matches.
- Keyboard focus is retained when collection opening choices appear, allowing Tab and Shift+Tab to reach New Window and Append Here.
- Search receives focus reliably when the toolbar popup opens, without taking focus from another control.

1.4.1 - 2026-04-20

Fixed
- Collection group order now follows the actual browser tab-group order more reliably.
- Live groups can now be dragged onto closed groups to place them there directly.

1.4.0 - 2026-04-20

Changed
- Group deletion now always asks for confirmation, with clearer wording for open and closed groups.
- Auto-created collections now follow the first group's name more naturally until the collection is clearly established.

Fixed
- New browser-created groups only inherit a neighboring collection when grouped tabs are directly adjacent in tab order.
- Ungrouped tabs now break collection inheritance for new groups instead of letting them join the nearest collection anyway.
- New browser-created groups no longer inherit the Uncategorized bucket.
- Canceled native Firefox group creation is cleaned up more reliably instead of leaving behind draft collections.

1.3.0 - 2026-04-20

Added
- Group delete menu with separate "Remove from Collection" and permanent delete actions.

Changed
- Sidebar and quick popup now follow Firefox light and dark content appearance.
- New collections ask for a name immediately instead of being created unnamed first.
- Popup panel control now toggles between opening and closing the side panel for the current window.
- Collection actions now switch between Open, Go to, and Close based on whether a collection is closed, partly open, or fully open, and Close only shuts the currently open groups.
- Refreshed collection and group action icons and hover states for clearer controls.
- Collection cards now highlight open and partly open state instead of the transient current-tab state.

Fixed
- Restored or newly reopened groups now join the current window collection context more reliably.

1.2.0 - 2026-04-14

Fixed
- Quick popup no longer shows the Uncategorized bucket.

1.1.0 - 2026-04-14

Added
- Dedicated Uncategorized bucket for groups kept after deleting a collection only.
- Bulk "Delete All Groups" action for Uncategorized.

Changed
- Live groups now use a small filled square marker; closed groups use a small outlined square marker.

Fixed
- "Delete Collection Only" now moves remaining groups into Uncategorized instead of creating fresh ad hoc collections.
- "Delete Collection + Groups" now requires confirmation before destructive removal.

1.0.0 - 2026-04-14

Added
- Initial stable release of collection-based organization for native Firefox tab groups.
- Sidebar management UI for collections and groups.
- Quick popup for fast collection access.
- Collection creation, rename, pinning, delete, and open flows.
- Group rename, move, delete, and drag-and-drop reordering.
- Saved snapshot support for reopening groups and collections later.
